# 类目与图片用途选择

跨类目复用的是视觉关系，不是样图的商品、数字或固定模板。先选用途，再从商品的形态、材质、动作和功能位置中选张力。下面为可选策略；塞星智能套图默认采用 [7 张分工](listing-seven-set.md)，其他指定任务按用户数量与用途执行。

## 图片职责

| 类型 | 第一任务 | 可用张力 | 文字与效果 |
| --- | --- | --- | --- |
| 平台商品主图 | 快速认出真实商品和变体 | 角度、光影、整洁轮廓、材质分离 | 导出前查目标平台当前规范；不自动加入广告文案、边框、动态光迹或道具。 |
| 白底功能主图候选 | 先识别商品，再理解一个真实用途 | 大产品、局部动作、必要手部、最多一个有依据的细节放大 | 白底为主，关闭广告大字；只保留真实作用点的克制效果，平台第一张图适用性另核对。见 [白底功能主图](white-main-use.md)。 |
| 商业主视觉 / 海报 | 一个清晰视觉主张 | 近大远小、斜向透视、紧凑裁切、产品穿字 | 主标题参与空间，参数贴对应功能；交互效果仅用于存在的作用点。 |
| 单卖点图 | 看出一项价值或功能 | 动作、尺度差、局部对照、视线引导 | 文案随局部商品或动作方向。无证据数字改成准确的可见描述。 |
| 材质 / 细节图 | 看清工艺、触感或材料在动作中的状态 | 微距、反射、纹理；需要张力时选择合理弯曲、压缩、垂坠或接触 | 普通细节图可无字；材质广告让字随动作。禁止用粗纹理、锐化、发光代替真实材质；见 [材质动作与张力](material-tension.md)。 |
| 使用 / 生活场景图 | 商品作用、操作与结果可理解 | 紧凑环境、近景商品、手部动作、局部景深 | 可无字；有文字则落作用点或场景空域。装饰特效不替代真实接触。 |
| 尺寸 / 适配图 | 尺寸、接口或对应关系准确 | 明确正交/三分之四视角、对应对象 | 数值、单位、标线和适配依据必须核实；透视图不能直接作为量测证据。 |
| 安装 / 步骤图 | 动作顺序和零件关系正确 | 一步一个动作、手和连接部位 | 局部箭头、编号随真实操作；不要生成说明书中不存在的机构。 |
| 结构 / 剖面 / 爆炸图 | 构造与位置有依据 | 可核实的拆解层次、透明/剖面和路径 | 需要真实内部资料或模型。缺资料可做外观细节或标清概念示意。 |
| 对比图 | 在同一条件看出差异 | 同机位、同尺度、同量纲比较 | 先定义对象、条件、证据；不凭空制造竞品故障或无依据百分比。 |
| 横幅 / 活动图 | 商品焦点适配渠道与裁切 | 沿画幅导向、商品与短标题交汇 | 版式随比例重构，不把竖图强裁成横图；促销价、时效和承诺需当前依据。 |

## 类目转译示例

| 商品特性 / 类目 | 从商品找动作与方向 | 材质 / 文字位置 | 避免误迁移 |
| 线材、数码接口、工具 | 插入、旋转、拉伸、扣合；轴线与连接处 | 参数靠实际功能点，金属反射和塑胶/织物区分；短光迹可演绎动作 | 不能每种工具都配电光；接口、功率、测试次数和内部芯片不继承。 |
| 家具、收纳、家居 | 支撑、滑动、开合、归位、承托；板面与边缘 | 木纹方向、织物、五金主次；文案靠动作/容量位置 | 不凭空加承重、容量或新机构；使用图需要实际支撑，不只是摆件旁加手。 |
| 厨房、小家电、清洁 | 倒入、按压、流出、切换、擦拭；出口与触点 | 壳体、金属、玻璃、水或污迹分别处理；文案靠作用点 | 没有真实流路时不做透明内部；蒸汽只用于有热作用的场景。 |
| 宠物、户外、运动 | 抓握、携带、补给、扣合；宠物或人作为动作参与者 | 产品更清晰，角色退后；参数贴相应部位 | 不以夸大人物/动物抢主角，不杜撰防护等级、健康效果或拉力测试。 |
| 美妆、个人护理 | 泵出、涂抹、打开、触感细节；瓶口与接触部位 | 包装文字、液体颜色/稠度准确；标签随瓶体或用量动作 | 不能借光效暗示不存在的即时疗效、成分或认证；微距皮肤不能冒充测试。 |
| 食品、饮料、日用品 | 倒出、拿取、打开、入口前动作；形态与包装 | 新鲜/酥脆等可见质感，字体围绕轮廓或道具框景 | 不改配料、份量、营养数字或包装；不把电光从接口复制到食物。 |
| 服装、鞋包、饰品 | 穿着、搭扣、提拿、弯折；版型、缝线、闭合位置 | 面料垂坠、织纹、皮革/金属区分；文字顺部件轴线 | 不改变服装版型、尺码、颜色和饰品数量；人/手选择随具体用途。 |

其他类目可从其可见形态、功能位置和材质归纳，不必等待新增一张模板。找不到可信动作时做形态或材质主视觉，不能捏造功能来填充流程。

## 套图分配

按用户数量与商品信息分配图片职责。例如外观、一个关键卖点、一个材质细节、实际操作、整理/生活场景。职责不够就少做或细化视角；不重复同一灰背景加大字来凑数。

共享商品身份、有限色彩、字体家族与材质基调；变化镜头距离、方向、主体尺度、光影和场景。每张都能说明为何需要它、为什么文字/效果位于那个位置。先验证一个代表方向，认可风格后再扩展；已授权完整套图且方向明确时继续完成，不重复索取确认。
