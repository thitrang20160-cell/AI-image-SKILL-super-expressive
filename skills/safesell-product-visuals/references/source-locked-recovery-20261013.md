# 源图锁定、修复与暂存恢复

本次实际案例为 AE261010 十件商品、每件七张图。用于复用执行方法，不是跨类目有效性或独立审核证明。

1. **同名变体按 SKU 图片 ID 锁定。** 白色 PET 的三个选项同叫 50Sheets white，却有不同尺寸。使用此前选中图片 ID S41f5766f5d294b2f9ed2a126f3929515J 恢复 76 x 101 mm、50 张；不按今天默认项或同名第一项替代。
2. **从真实选中图取得高清 URL。** 含查询串的 CDN 请求返回 429 时，先在商品页点击已选中的 SKU 图片，读实际显示的无查询图片地址。100 支笔芯据此得到 800 px 选中图。不得猜一组 URL 或绕过真人验证。
3. **商品资料覆盖旧 AI brief。** 紫色 G1002E 实图是浅紫平面、紫包边、两白扣，无三道面槽；旧 brief 的灰边/面槽错误已修正。文件袋物面字是 CLEAR HOLDERS，白斜线与印字方向分别核对。笔芯不能因宏观形状像笔就放过凸出的彩色球头。
4. **重绘失败后改用固定商品层。** 十个文件袋连续出现少件数、比例不等时，用同一个核对过的产品层按固定位置排十件。50 转环采用源图五型号各十件。针管笔的 AI 重绘不断生成号码时，改用实际源图印字像素；记录低源分辨率，不能声称高清微字或推断品牌。固定源层/裁切是商品修复，不计水印去除。
5. **合成也要看输出。** 裁切笔芯曾混入邻近第二根，转环裁切曾残留参数线，印字补片曾包含白背景边缘。查看实际输出后收窄裁切和遮罩，未通过版本保留，不凭脚本件数或执行成功批准。
6. **属性保存后双向读回。** 暂存前端把嵌套尺寸映射清空。将映射保存为 JSON 字符串，同时提供五个独立数值字段；源工作台与暂存记录分别读回比较。不能把保存按钮成功当作字段完整。
7. **更新现有暂存记录。** 使用已验证的 SOP“加入暂存区”兼容入口按店铺与 SKU 更新同一记录。旧逐条 to-staging 路由会新增行，不能混用。失败或超时先读回 ID、图片和文案再重试；不写应用数据库，不调用浏览器私有接口。
8. **用户变更要求后继续其余工作。** 本批用户明确跳过余下检测，记录原话并停止调用；未知保留、已有结果不改写。继续逐图商品自查、C2PA 副本导出、图床公开 GET 字节比对、暂存和表格。不得因检测跳过而豁免商品错图，也不得等待已被用户取消的 API 密钥步骤。
9. **图片链接按完整字符串核对。** 本次读回发现一条尺寸图 URL 末尾多了无关文字；`includes(expectedUrl)` 无法识别这种错误。填写后将焦点移出输入框，保存前读取实际 textarea value，按每行 URL 精确比较；保存后对 SOP 和暂存的整个有序数组再次精确比较。图床 URL 的 HTTP/hash 验证不能替代暂存字符串检查。页面刷新关闭未保存窗口时，以真实读回结果恢复，不从按钮调用成功或超时推断已保存。
