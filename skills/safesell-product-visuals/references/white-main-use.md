# 白底功能主图

用途：用户希望主图有表现力，同时保留白底、清楚商品身份和紧凑画面。属于 master-use 设计候选；纯白底 master 仍保留。使用图出现在现有商品页不等于获得平台第一张图的普遍许可。生成设计和上架适用性分别判断。

## 画面决策

先选择一个能说明商品用途的真实动作，按 `商品 → 触点／连接 → 局部使用对象 → 必要细节放大` 组织。背景以白色空域为主；本次用户偏好的约 2/3 白底是背景构图目标，不是产品占比、硬性像素阈值或平台规则。主体仍需足够大，关键轮廓可辨，不为留白把商品缩小。

- 主体用斜向轮廓、前景尺度、材料分离和清晰柔光表现张力，无广告大字、未知参数、卖家标记或无关场景。产品本来的品牌和面板标识保留并核验。
- 使用对象只保留解释作用点所需的局部，常从边缘进入；可用面积与颜色由当前产品决定。避免整间房、整台设备、全身人物或大面积背景抢焦点。
- 手与前臂按需解释握持、按压或连接，不露脸；选“不出现人物”时不用手，改用商品与局部对象的关系。检查手指、腕部连续、接触点、物体尺度和关键部位遮挡。
- 放大窗最多一个，优先真实功能面板、连接点、接缝或纹理。仅在当前 SKU 有清楚原图时使用；窗内和主体必须是同一个部件、同一变体与状态。否则取消放大窗，而不是发明细节。窗应明显次于产品，不像第二件商品。
- 功能效果只在有依据的真实作用点出现：例如蒸汽、流出、水滴或擦拭边界。先看商品是否有此功能；不把电光、爆炸、全轮廓发光或漂亮烟雾当成跨类目默认效果。

## 类目转译

| 商品 | 局部场景／动作 | 可选放大点 |
| --- | --- | --- |
| 挂烫机、清洁工具 | 手握商品与一小片衣料／被清洁表面接触 | 真实面板或接触头 |
| 充电线、连接配件 | 线材主体加一个真实匹配接口局部；接口连接正确 | 接头或编织细节 |
| 家具、收纳 | 局部桌面／物品支撑、滑动或开合 | 五金、连接或真实材质 |
| 美妆、日用品 | 泵口与少量真实用量或手的拿取 | 真实瓶口、包装纹理 |
| 服饰、箱包 | 局部穿着、提拿或闭合动作 | 缝线、扣具、面料 |

没有可信动作时保留纯白底主图，或只加入有依据的局部细节；不硬凑场景。不同产品不能套同一种布料、蒸汽、手势或圆形面板窗。

## 审核

同时检查完整画面和缩略图：第一眼认出商品；第二眼理解用途；第三眼才看到放大细节。逐项核对主体/窗内的接口、按钮、图标、材料尺度及动作。白底占比和视觉评分不能覆盖商品结构错误。工作稿应标明 AI 参考重绘、独立审核真实状态及平台适用性尚待确认。

## 平台适用性

用户偏好的白底功能展示可以先制作，但不自动标为“平台主图合规”。沃尔玛美国官方指南强调主图无缝白底、不能展示未包含附件，部分大件可用预期环境；类别还有额外要求。其他站点或亚马逊分别核对当地当前类别规则，不能从沃尔玛展示页推断许可。
