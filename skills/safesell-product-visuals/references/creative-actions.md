# 把创意与商品联系起来

当前用户要求严格跟随 11 张原始样本。选场景前先读 [样本风格锁定](sample-fidelity.md)，以具体原图的拓扑、材质和动作决定创意规模。下表是可选方法，不授权从框景自行扩展为纸页风暴、发光书或故事传送门；这些方向已被用户否定。

高级商业图的材质、光影和字体是基础，视觉记忆点还需要一个能解释商品的动作。用一句话同时说清商品主张与画面动作，读者应能看出二者的联系。一次验证一个动作，不堆砌星空、巨兽、火花、纸页、玻璃泡泡等无关元素。

## 可选方向

| 方向 | 选用依据 | 视觉动作 | 主要验收点 |
| --- | --- | --- | --- |
| 形态呼应 / 空间框景 | 商品有明确轮廓，可用相关物件建立情境。 | 与轮廓相关的道具形成大弧线、画框或层叠空间，商品完整放在焦点。 | 道具与商品相关；关键结构无遮挡；背景不吞掉商品；道具的连接若重要须检查。 |
| 真实使用动作 | 商品用法与接触关系有依据。 | 手操作、书籍被整理、液体流入等一个真实动作。 | 接触点、方向、支撑、尺度与原始依据匹配，未显示的结构不凭空补充。 |
| 材料 / 工艺细节 | 原图可辨别外观细节；需要张力时材料有可支持的状态/接触。 | 局部放大与侧光；按商品选择回弯、受压、垂坠或接触对照，见 [材质动作与张力](material-tension.md)。 | 材料事件先于附件；纹理相对尺度和连续性一致。生成微纹理不称精确复制，剖面需资料。 |
| 前景递送 / 极近机位 | 商品在已知角度仍可识别，目标是品牌广告。 | 产品接近镜头，其他元素退后，形成清晰近远层次。 | 主体身份不被夸张透视改变；手/动物接触可信；不传递参考品牌与功效。 |

样本 3/6 的前景递送与嵌套框景是风格方法；不直接复制猩猩、猫、眼镜、包装和标语。样本 8/10 的剖面与内部系统需要核实结构，不能作为单张网站图输入的默认创意。

## Brief 先锁四件事

```yaml
primary_message: Give books an orderly home
creative_action: Cream page arcs echo the rounded arch profile of the bookends
product_truth: Two light-tan arch boards and hollow black rectangular wire feet
scene_truth: Advertising page arrangement; not a load test or actual supporting use
must_show: [both board silhouettes, both complete wire loops, both attachment points per board]
must_not_imply: [unknown capacity, actual dimensions, verified wood species, real 3D model]
review_deviation: []
```

场景里每个元素都有用途。装饰占比、主次、材质、遮挡和留白看实际输出，不把提示词当保证。如果“商品作为框景中心”的目标没达到，先调整主体尺度或装饰位置，不先加更多特效。

## 遮挡的修改顺序

1. 检查原图允许验收的关键结构。接头、脚、附件需要可见时，记录被谁遮住。
2. 移动完整商品对象及其连接附件；比如后方书挡与底座整体左移，而非单独拉长脚来绕开前方木板。
3. 再考虑移动装饰、换已有可核实角度或减少道具。不能删除需要保留的商品部件。
4. 隐藏部分仍未知，不能因构图漂亮而标为结构通过。同一问题连续两次失败时依照主技能停止该方向的重复重绘。

书挡第三轮用一次位置修正露出后方完整底座；这是可见构图问题的改善，不是未知背面或承重的验证。纸页没有严格按单本书绑定，记录为概念搭景偏差，不假称完成精确纸页物理仿真。

## 推荐表达

说明“本轮哪个动作已做出、哪些可见结构与原图一致、哪里仍未核实”。可以提出人工审美偏好，但不能宣称广告转化已提高或完整复刻样本质量。广告候选与平台主图用途分开；正式导出时按实际请求核实对应平台要求。
