# 充电线套图校准记录

这是参考引导重绘的制作复盘，各轮认可状态分别记录；不是 CAD 渲染。商品依据 Walmart SKU 3742125683：白色编织 USB-A → USB-C 线、6 ft，原图可见白色锥形壳、银色圈、双开孔和收纳按扣束带。样本品牌、功率、次数、销量和内部结构均不迁移。

## 原样本与第一轮的差距

- 样本 7：前景物体与大字参与同一构图。第一轮主体摆放较完整、标题只在空白区，缺少挤压感与叠层。
- 样本 9：线材把设备、透视和卖点连起来。第一轮延展广告只是悬浮 S 形与蓝框，长度主张没有空间关系支撑。
- 样本 8：宏观材质需要精确尺度。第一轮把外壳颗粒、编织块和蓝色边光做得过强；显眼不等于真实。
- 样本 11：动作指向可见结果。连接和按扣收纳图已有有效关系，应保留，而不是每次重做全套。

## 第二轮实际变化

1. 主视觉重新生成：放大前景 USB-C，后方 USB-A 与盘线形成纵深；深蓝上部与浅灰下部区分层次，银色反射有更明显明暗。可编辑蓝色标题局部落在壳后。
2. 延展图重新生成：后方电脑的 A 端连接前景手中手机的 C 端，一条可见线跨桌面形成距离；6 FT 是商品页线长，场景不作为尺寸证明。
3. 材质图编辑：蓝色发光边移除，白壳颗粒减弱、金属反射收敛。编织仍偏粗，没有据此宣称保真通过。
4. 连接图编辑：保留接口与路径，加强接触阴影和前景局部对比。手部只参与操作，不露脸；电池图标仅为演示。
5. 收纳图保留：按扣闭合与束带收拢的结果可读；束带下的隐藏线材路径仍未核实。

## 复用原则与剩余问题

每轮以原商品图和原样本重新校准，不把上一轮候选自动提升为事实或审美锚点。受控夸张可以提升尺度、反射、留白压力和图文关系；不要改变接口、壳体比例、件数或附件。

当前还有：微观端子并非准确触点阵列；浮雕 Logo、双开孔和壳体比例有跨图漂移；宏观编织仍偏篮纹；盘线隐藏段无法完整追踪。精确上线要求应转为独立商品层、可靠多角度图或真实模型控制，不能靠再次堆叠“超精细”提示词解决。

第二轮更清楚地表达了空间和材质主次，但还没有达到原样本全部的视觉强度。独特形态与文案融合、严格纹理校准、跨图商品一致性仍需继续验证。底图、排版与风格结论分别记录，用户未反馈前不写成“复刻成功”。

## 用户对第二轮的追加校准

用户指出张力仍不足，并再次提供样本 9：需要文字随商品的位置、大小与方向变化，前后错落，参数贴作用点，交互光效表现动态。第二轮的局部遮字没有完整做到这些关系。后续先做连接图的单张空间文字候选，按 [空间文字与交互动势](spatial-type-and-motion.md) 重新审核；第二轮保留为制作历史，不抹去不足。

## 已认可方向与整套扩展

第三轮连接图的空间文字方向获用户认可，并形成 SKILL v1.0；认可范围是视觉关系，非全部商品工程细节。第四轮补齐主视觉、材质、收纳与延展，连接图保留第三轮。用户评价整套“不错”，随后指出材质还需加强张力。

## 第五轮：材料在动作中成为主角

用户再次提供原样本 8 和 7，要求识别设计意图并完善。依据 [材质动作与张力](material-tension.md) 更新 SKILL v1.1，同时只重做材质图，其余四张保留第四轮。

- 原第四轮材质图有织纹与字物关系，但焦点仍偏大接头，线材舒适摆放，主要在命名材料。
- 新候选用极近前景的饱满回弯作材料事件，USB-C 退到右上次要位置；BRAID 在中后层被线材遮挡，NYLON WEAVE 随外弧方向。
- 一次生成、一次定向编织纹理修订。修订后中远段更细、更呈斜向编织；最前景仍有偏大的格纹感，记录部分改善，不称精确保真通过。
- 当前没有真实内部资料，因此不迁移原样本 8 的剖面、未知芯线与 48000+；不迁移原样本 7 的扣具、竞品磨损与承重隐喻。
- 第五轮之后，用户评价“不错的”，并要求试做挂烫机；挂烫机套图随后获“做的很好”反馈。这里将充电线材质张力和跨类目的衣料接触表达分别登记为审美种子，编织尺度、商品微观细节及性能未因此转为已核实。配方卡见 `recipes/cable-spatial.v1.json` 与 `recipes/steamer-tactile.v1.json`；两者各验证一个 SKU，不能称所有类目已验证。
