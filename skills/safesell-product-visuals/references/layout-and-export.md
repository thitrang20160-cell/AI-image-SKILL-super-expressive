# 分层排版与导出

适用于商品位图已经生成，且需要精确标题、卖点或系列文字的阶段。优先用编辑器的原生文本层；没有设计工具时可用 SVG/HTML 作为可编辑文字版式。商品仍来自 image_gen 的实际 PNG，不画矢量商品来冒充生图。

## 制作步骤

1. 查看原尺寸底图，记录实际尺寸和留白。确认商品形态、件数、使用关系后再排版；结构待核实的候选可以继续试排，但保留该标记。
2. 用原尺寸画布完整放置底图，默认不裁切或放大。若需裁切，另记裁切框并检查接口、底座、附属品和商品轮廓是否被截断。
3. 从真实留白确定标题区域，留足字形下降部与安全边距。比如书挡第二轮要求上部 32% 留白，实际左侧拱顶从约 y=306 开始，因此按实际像素排版，不按期望值覆盖。
4. 标题只表达一个主张；解释文案补充使用情绪/作用。短标签只写可见事实，没有依据的材料种类、尺寸、承重、认证、测试次数都不加。
5. 文字作为可编辑节点，标记字体、字号、颜色、行距、坐标与底图版本。Logo 使用独立用户素材。若需叠前后关系，保护关键轮廓，不用文字遮挡来隐藏底图错误。
6. 查看最终 PNG 和实际展示尺寸，逐字符检查标题与数字，检查碰撞、截断、对比度与最小可读性。大标题在缩略图应仍能识别，解释文字是否可读取决于实际用途，不把桌面预览当所有场景验收。
7. 先保存独立底图、可编辑 SVG/原生设计文件、导出工作稿、文案与内部记录。SVG 内嵌底图可避免离线打开缺图；文本仍可编辑，但目标机器缺字体时会替换，交接字体或另存轮廓版时保留原始文本版。
8. 按 [真实性与生成后处理](realism-and-postprocess.md) 对实际导出文件做声明处理、像素水印检查与任务完成判定，再保存用户最终副本。原始生成文件保留；工作稿声明状态不能继承到后来重新导出的文件。未完成隐藏水印去除时，不把副本放进“已全部处理”下载包。

## 商品与文字的前后关系

先选一句主张与交叠位置，再生成底图；排版时按实际商品边缘校准。允许非关键文字局部被前景商品盖住，但缩略图中主张、数字和单位仍应读得出。关键接口、动作与结构不被文字遮住。

可重复引用同一底图，用原生 SVG 遮罩只恢复商品覆盖文字的局部。闭合轮廓可用 `clipPath`；线材等开放路径若靠描边遮罩，应使用 `mask` 中的白色描边与黑色底。`clipPath` 不按描边宽度裁切，开放曲线可能按填充区域盖掉整块文字。记录遮罩坐标、宽度、底图版本，在实际 PNG 中检查边缘、光晕和误擦字；遮罩不应修饰或隐藏底图结构问题。

这种排版恢复的是生成候选的像素，不是已核实的原商品层。保持图像审核与排版审核独立。

## 示例输出链路

书挡第二轮：`image_gen 无字 PNG → SVG 内嵌原 PNG + text 节点 → 浏览器原尺寸 canvas 输出 PNG`。浏览器是排版/矢量渲染工具，未改变商品位图。使用页面明确的生成按钮，再读它生成的下载链接；不要用浏览器 evaluate 执行隐蔽的页面写入或未公开 API。

项目里的 `build-posters-v3.cjs` 仅组装文字与自包含 SVG，便于调整后重建。它不是产品绘图器，不接入 ERP 队列，不发送模型请求。

## 独立审核状态

- `image_review`：商品形态、材料外观、光影、使用关系、缺失资料。
- `layout_review`：实际文字、版式、裁切、导出尺寸、展示尺寸。
- `overall_status`：以上任一需审核时仍为 `needs-review`。

第二轮排版已核验，但功能底座被遮挡，所以整体不能改成 `reviewed`。文字层精确也不能使产品成为真实 3D 或经过工程核验的图片。
