# 成本、竞争与成交机会驱动的定价曲线

用户于2026-10-14进一步要求根据成本变化和竞争价格找定价点。原“采购到手成本加15美元”保留为对照方案，定价标准升级为约束下的预期总利润。不得把假设模型的最优点说成已经用销量验证的真实最佳价格，也不因此自动改动已上架商品。

## 输入先对齐

- `P`是买家税前到手总额，包括向买家收取的运费；本项目免邮时等于商品售价。
- `C`是每单完整可持续变动成本，包括实际采购、寄美运费、不可抵扣税费、包材、未包含履约及支付换汇等。首单价不能代替补货价。
- `M`是同规格、可购买、同市场竞品到手价的代表中位数；先剔除不明运费、缺货、明显不同件数/品牌/材质的报价。配送、评论和品牌差异记录后再选择竞争折让参数，不能把无法匹配的价格强行平均。
- `r,a,h`分别为佣金率、广告占售价比例和售后预期损失比例。以`aP`建模只是情景假设；有点击费与转化数据时，应按`广告支出=点击量×CPC`等实际结构计算，避免把依赖转化的获客成本当常数。
- `g,m,t`分别为最低每单利润、最低利润率、成本上涨压力比例。未由用户确认的数值标为建议参数。
- `k`是考虑配送/品牌/评论差异后的竞品价格上限系数。`beta`是价格敏感度，需要真实数据校准；没有观测时只能做情景分析。

## 平佣金时的连续解释公式

令`s=1-r-a-h`。基准每单贡献利润`u(P)=sP-C`。

最低可卖价：

`L=max((C+g)/s, C/(s-m), (1+t)C/s)`。

分别保证最低利润、最低利润率、成本上涨后不亏。若`s<=m`且C>0，则无满足该利润率的价格。竞争上限`U=kM`。`L>U`就淘汰、换货源或重新验证差异化，不把售价压到亏损区，也不无依据提高U。

为了给出可调整曲线，采用一个明确的工作假设：

`Q(P)/Q(M)=exp[-beta(P/M-1)]`。

它只是相对成交量模型，不是实际转化率或订单数；beta不来自供应商销量或累计评论。目标函数为`J(P)=(sP-C)×Q(P)`。在平佣金、上述需求模型、成本完整且其他条件不变时，无约束最优点：

`P_model=C/s+M/beta`。

若可行，则`P_start=min(U,max(L,P_model))`。该解析式解释连续曲线；实际按美分重算佣金及约束，再比较可行价格的目标值。不要盲目把建议价改成.99后跌破利润底线。

服饰等分档佣金不能把某一档费率套到整个曲线。使用`佣金(P)`逐价计算，考虑15/20美元等边界，搜索所有可行价位；不直接套平佣金解析解。

## 当前例子与参数性质

默认展示仅为合成例子：C=10美元，M=24美元，佣金15%、广告10%、售后损失5%，g=5美元、m=20%、t=20%、k=0.95、beta=3。连续参考区间约21.43至22.80美元；连续最优点约22.29，考虑按分佣金舍入的示例搜索点22.23。精确到分仅是程序计算精度，不能代表真实经济最优精度。

beta=3意味着价格比M高10%时，相对成交量在该假设中约为原来的74%，不是已经观测的事实。至少查看不同beta情景的价格稳定性；建议价对假设敏感时保留区间，不伪造唯一最佳价。

`g=5,m=20%,k=0.95,beta=3,t=20%`都是分析示例/建议值，未自动成为用户已批准的硬阈值，也不是沃尔玛官方标准。当前候选默认规格、完整补货成本与可比价未核完，不能套这个合成例子的数字放行。

## 校准与验收

有真实数据后，以每个价格下的同口径曝光/点击、订单、每单成本和可比竞争价校准Q(P)。按流量来源、广告、库存、配送、季节和listing变化控制混杂；不能把前一天与后一天所有变化都归因于价格。零订单和小样本保留不确定性，不用短期偶然零单确定需求曲线。

实际比较每千次合格曝光的贡献利润，连同转化率、订单量、退货损失一起判断。没有足够订单时仍称“启动价/候选价”。测试价格需要相应店铺与SKU的实际改价授权；模型制作不等于授权自动改价或定时调价。

`scripts/pricing_curve.py`读取情景JSON并按美分搜索，不联网、不推送；成本/竞品核验仍由选品闸门处理。输出固定保留`hypothetical-demand-not-calibrated`，不要直接映射为`selectionReview.profit=pass`。例子位于当前任务`pricing/curve/scenario.json`，不是模板中的真实商品报价。

```text
python -X utf8 -B scripts/pricing_curve.py --input ./work/input.json --report ./work/report.json
```
