# 流量先行，利润通过后制作

适用新选品及其后续制作。用户指定顺序：看流量 → 看利润（竞品对比） → listing → 图片 → 一致性审查 → 按授权暂存或上架 → 实际回读。旧成果保留，新顺序不自动授权修改旧店铺售价。

## 第一关：目标市场需求

先以沃尔玛美国站商品页、站内搜索或已授权分析工具寻找需求。保存关键词、商品/类目、观察时间、市场/地址口径、数据来源及信号层级。优先近期购买标签、评论增长、搜索量或店铺实际曝光/点击/订单；仅有搜索结果存在或累计评论，不能声称已核实近期流量。

速卖通累计已售量支持供应端热度，亚马逊销量/评论和季节趋势提供辅助线索。不能把它们写成沃尔玛流量。圣诞/冬季关键词只是方向；旺季前的增长、供货和预计到达时间仍需核对。平台不提供精确流量时说明可得代理指标与局限，不捏造搜索量、转化率或日销。

给出 `pass / reject / hold` 和理由、可读证据。是否充分由实际数据和竞争程度判断，不固化一个无来源的“累计销量X必过”规则。没有近期数据时保留候选，不直接进入制作。

## 第二关：可持续利润与竞品

1. 锁定原链接的默认销售规格、数量、尺寸、颜色和配件。首单价可试单，正式模型使用同规格可重复补货价，保留优惠资格、限购和恢复原价后的利润。
2. 记录美国沃尔玛可购买竞品的实际所选规格、商品价、买家运费、到手小计、评分/评论量、配送天数、卖家与日期。优先多个有代表性的可比报价；只有一个时明示样本不足。亚马逊作辅助参考，不能替代沃尔玛可比价。
3. 同款优先于高星。件数、尺寸、材质、品牌、配件和服务不一致时列差异；单件折算可帮助比较，不把不同多件包装价格线性放大为可卖价。页面推荐卡片价格不能冒充主商品购买框价格。缺运费、缺货和不可购买报价不能当已验证市场上限。
4. 以真实履约路线核成本。当前项目的中国发货方案和美国WFS方案分别核算，不叠加两次物流，也不把美国本地快递价套到跨境路线。配送时效较慢或品牌/评论较弱，不能无依据采用对手溢价。
5. 按类目查询当前官方佣金；佣金基数包括商品价及向买家收取的运费等适用费用。税的处理依据实际费用和官方口径，不能把代收税当收入或把未知税费填0。

记 `R = 商品售价 + 买家付运费`，`C = 可持续采购价 + 寄美运费 + 不可抵扣采购税/关税 + 包材 + 未包含履约费 + 支付/换汇费 + 其他每单变动成本`。

`每单变动成本后利润 = R − 平台佣金(R) − C − 广告支出 − 退货/退款/补发预期损失`。

固定开支和所得税未纳入时标明，这个数不冒充企业最终净利润。广告费率和售后损失率属于有来源的历史数据或明确估算，不能标成实测。无投放方案可以有0广告基线，但同时列出带广告的情景；用退货率直接乘收入只是简化损失预留，需明示。

本项目用户于2026-10-14先确认“采购到手成本加US$15定售价”，随后要求按成本变化与竞争价格总结曲线并寻找更佳定价点。因此加15保留为对照方案，新标准采用[成本、竞争与成交机会定价曲线](adaptive-pricing.md)：完整成本决定利润底线，同规格竞品决定可接受区间，再在明确需求假设下求启动价并用真实数据校准。不得把模型点冒充已验证最佳价，也不授权自动修改已有店铺售价。

按实际成本和竞争区间选择价格：成本底线、预估利润、利润率、可比竞品到手价与配送差异同时满足才通过。若用户没有最低利润目标，可提出初筛建议（如每单至少5美元且利润率20%），明确它是分析建议，不能记为用户已确认阈值。可重复成本未知、成本不完整、沃尔玛可比价或流量未核时为hold。实际测算亏损或可接受市场价低于成本底线时淘汰或换货源；不能靠虚构功能、换规格或未证实溢价通过。

加价15不能覆盖所有成本。除基准外，按有依据或明示的假设做采购/运费上涨、广告和售后增加的压力情景。通过的依据包括利润仍有余量；负值必须暴露。数量、成本、售价、平台费和配送改变时重算。

## 输出和前置闸门

每件保存：流量结论及证据、锁定规格、首单与补货成本、履约路径、当前类目费率、广告/售后假设、竞品规格和到手价、候选售价、利润/利润率、压力结果，以及 `pass / reject / hold`。通过后才写listing和生图。旧文案和图片可保留，不能因此跳过新商品的利润审查。

`scripts/evaluate_selection.py` 只读JSON并计算，不联网、不验证人工判断真伪、不写业务系统。输入以 `products` 为数组。每件字段：

```json
{
  "sku": "EXAMPLE-001",
  "source": {"selectedVariant": "Actual locked variant", "evidenceRefs": ["source.json"]},
  "traffic": {"status": "pass", "market": "Walmart US", "evidenceRefs": ["traffic.json"]},
  "economics": {
    "costStatus": "verified-repeatable",
    "costs": {"itemUsd": 4, "shippingToUsUsd": 2, "nonRecoverableTaxUsd": 0, "packagingUsd": 0, "otherFulfillmentUsd": 0, "paymentFxUsd": 0, "otherVariableUsd": 0},
    "costEvidenceRefs": ["cost.json"],
    "retailPriceUsd": 21,
    "customerShippingUsd": 0,
    "commission": {"scheme": "flat", "rate": 0.15, "evidenceRefs": ["fee.json"]},
    "adRate": 0.10,
    "returnLossRate": 0.05,
    "assumptionBasis": "Explicitly modeled rates, not historical actuals",
    "stressCostIncreaseRate": 0.20
  },
  "marketReview": {"status": "pass", "platform": "Walmart US", "comparableDeliveredPriceCapUsd": 24, "evidenceRefs": ["competitors.json"]}
}
```

示例纯属合成，0成本项须在真实证据中确认，不能复制给实际商品。顶层 `thresholds` 可按已确认目标给 `minUnitContributionUsd`、`minMargin`；未提供则只作正利润底线核对，仍要求实际流量/竞品/完整成本及压力结果。`apparel-us-2026-10-14`佣金方案实现该日官方5%/10%/15%价格档，仅在当前类别和官方规则仍适用时使用；其他类目填实际flat费率，不默认全部15%。未知成本保持null，脚本不会填0。

阶段结果与原`audit_batch.py`配合：新批次设置`selectionGateRequired=true`，每件`selectionReview.traffic`和`selectionReview.profit`分别带pass及证据，利润审查记录`approvedRetailPriceUsd`。下游审计核对前置审查及价格绑定；旧批次字段缺失不会被追溯改价。
