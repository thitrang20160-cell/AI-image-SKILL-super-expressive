# 速卖通选品、亚马逊调研与英文 listing

新候选先按 [流量、利润与竞品闸门](traffic-and-profit.md) 执行：沃尔玛需求证据先于利润核对，两个闸门通过后才制作listing和图片。本文件的原页事实、采购预算和侵权初筛同时构成后续核验依据，不能用速卖通高销量直接代替目标市场流量。

## 商品级选品

批次至少记录：内部 SKU、速卖通商品 ID/直达链接、所选规格、观察时间、目的国/币种、商品价、运费、到手小计、免邮条件、促销类型/资格/限购、销量或已售量原文、评分与评论量、来源证据、缺项及风险。

区分搜索卡片线索、商品详情确认和最终锁定销售规格。搜索页“最低价”可能属于不同件数或颜色；价格与销量必须注明层级。父链接已售量不等于当前变体销量，“100+”只保留为下限，不改写精确销量。

本项目采用美国、USD，采购筛选为：

- 优先商品价 US$0.99 促销；标注首单/新用户资格、限购、运费、凑单或券条件，不声称普遍可买。
- 另接受 US$1–3.99 的免邮促销品。
- 普通免邮商品 US$4–30；普通付运费商品的商品价加运费 US$4–50。

商品价、运费、税和小计各列分开。没有结算税依据不能写“含税到手”。未知运费不能填0；有最低消费门槛不能写无条件免邮。报价与限购绑定账号状态和观察日期，临近采购再核实。

用销量、评论量、店铺记录、规格清晰度、原图可用性及同质化程度筛候选。没有用户指定门槛时自行采用合理比较口径并说明，不伪造统一平台排名；高销量可记父链接层级，不能证明质量或持续需求。

初筛品牌、Logo、人物/卡通形象、明显复刻设计、授权限制、受限类别及认证依赖。普通外观和无 Logo 不等于已完成专利检索；记录“低风险初筛”及未核权利项，不承诺绝对不侵权。供应商手册、包装或图片出现第三方品牌时核清与本 SKU 的关系，不能自动改成用户品牌并宣称有授权。

## 锁定原链接规格

1. 记录当前真实选中的颜色、型号、件数、尺寸和选项标签；保存能显示选中状态的页面证据。
2. 展开规格、描述与相关尺码图，建立 `source.lockedAttributes`。尺寸要记录量测端点和对象：单件、整套、收纳盒、卷外径、标签本体不能互换。
3. 下载或保存当前 SKU 的原图并记哈希。图库混有其他规格时逐张归属，跨颜色结构共用尺寸图的推断要明示。
4. 刷新、登录或换页后重新确认锁定选项；默认从50件变200件时选回50件，不能修改已定 listing 来迎合页面新默认。

在真人验证处让用户手动完成，保留页面和所需动作。不要绕过验证；转去整理已取得的证据、竞品、文案或其他 SKU。浏览器连续失败先按工具文档恢复会话或新建同浏览器标签，不一遍遍调用已失效目标。

## 亚马逊同款与评论

以原 SKU 的结构、用途、件数、尺寸、颜色及配件找同款。先排匹配度，再比较星级/评论量；高星不弥补不是同款。保存 ASIN/直达链接、选项、评分/评论数原文、价格/运费或 Prime 门槛、观察时间、匹配差异。

用户未给星级/评论门槛时可选合理筛选值并说明；同款少时诚实降低候选充分性，标“相似款参考”，不把低评论结果标成高评论同款。搜索卡片只能支持卡片实际显示的数据；未打开评论页就不能声称已分析真实差评、做工问题或买家原话。

提炼关键词、信息顺序、真实买家关注点与差异化表达。重写原创英文，不复制对手标题、五点、描述、品牌、图片、认证或独特广告语。对手的承重、耐候、粘性、材质牌号、寿命、抗菌和测试数据不能移植。

## 沃尔玛内容与售价

执行时查询当前美国站官方 Product Details、Image Guidelines、所选 Product Type 的 spec 和 Listing Quality 建议。旧 PDF 的标题字数、要点数量、描述词数不能固化为所有类目硬限制；不要混用加拿大规则。

标题以品牌（已确认）、产品类型、关键区别、规格/件数为骨架；五点覆盖实际功能、数量/包含物、使用方法、适用对象与重要限制；描述用自然英文连贯说明。关键词不堆砌，不加入销量冠军、免费运费等营销词，不为达到词数编造功能。后台属性与可见文案采用同一事实来源。

Listing Quality 还涉及价格、配送、库存和评论等组件。只完成内容优化时，不承诺总分或销量必然达到某值。

售价在前置利润阶段另做决策记录，不能把采购价、亚马逊价格和推荐售价混成同一个字段。优先当前美国沃尔玛可购买的同规格竞品到手价；亚马逊辅助验证。不同包装数、品牌、尺寸和配送承诺逐项标差异。仅有参考采购价可计算假设或乐观下界，不能报实际利润或通过。可持续成本及履约路径核实后，按实际类目佣金、广告与售后预留重算。本次“原来有竞品调研”不代表过去已核过完整利润；找不到则补算。

用户要求保留已生成 listing 时，保存标题/五点/描述快照或哈希，补属性和图片 URL 后逐字读回。若原文案含错误，修复受影响的事实，记录修改理由与范围，不做无关润色。
