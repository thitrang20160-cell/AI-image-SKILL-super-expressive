# 外部服务适配合同

公开包提供本地制作/审核/价格核对、原图参考和图床实现。生图、合规检查及平台写入分别使用操作者自己的工具、账号与实际接口；私有商业后台不作为依赖打包。配置见 `config/runtime.example.json`。不得把配置模板或模拟数据称为已接通服务。

## 生图工具

调用客户端可用的内置image_gen时，按skill传入真实本地参考路径。其他客户端先确认实际图像工具、参数与费用授权，制作适配器将真实调用与输入/输出哈希绑定；当前本地检查器的工具合同不自动证明其他服务适配通过。没有可用图像工具时仍能准备brief、核对商品和审核已有图片，但不能声称已生成。

## SafeSellAI合规服务

需要使用者的服务地址、账号/令牌、当前接口规范及计费规则。适配器至少返回请求ID、实际输入图/文案摘要、原始响应引用、风险状态及人工复核范围。认证/服务失败保持unknown，不填“低风险”；有效旧回执仅复用相同字节及同一检查范围。若无授权服务，先完成源图、文案、商品和视觉审核，保留合规服务待执行状态。

## Walmart或卖家系统

使用官方API或使用者授权的卖家应用，按当前US站市场/分类取得schema。适配器需要：店铺身份和节点读回、暂存upsert/读回、feed提交/逐件状态、目录SKU/售价/库存读回，以及GTIN豁免资格和状态核对。API凭据不进入batch、日志或skill，写入前核对精确授权店铺/SKU/库存/售价。

写入前调用本地批次审计器；它不发布，不替代官方schema或API回执。未知提交先查询同一feed，不盲重传；仅重试可确认失败或官方要求重提的SKU。完成以真实逐件状态及目录/库存读回为准，不能用ACK或Feed PROCESSED代替。

本仓库未实现某个私有卖家服务的专有API路由，不包含可直接接管现有店铺的密钥。换服务只适配实际接口和证据合同，不改写用户授权或跳过审核。
